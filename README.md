# Galilean-and-Lorentzian-transformation
These short codes describe the method for Galilean and Lorentzian transformation
The set of Galilean transformations (assuming the motion takes place only in the x direction):\
x'= x - vt \
y'= y \
z'= z \
t'= t.\
So, now the coordinate transformation (T: $R^4$ -> $R^4$) is represented by the matrix M.
The set of Lorentzian transformations (assuming the motion takes place only along the x direction):\
x'= $\gamma$(x - vt)\
y'= y\
z'= z\
t'= $\gamma$(t-vx/c^2).\
Defining $\beta$ =v/c we get the desired matrix M for this transformation (T: $R^4$ -> $R^4$).
